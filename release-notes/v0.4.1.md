# Lineage DeX 0.4.1

Experimental prototype / prerelease for Lenovo TB-X306X with LineageOS 20 (Android 13). Independent project; not affiliated with LineageOS or Samsung.

Explicit freeform launch-mode request for Android 10–13, floating monitor apps by default, reversible developer-settings setup, and 1920×1080 monitor scripts. **Requires the one-time setup and a tablet reboot. Runtime multitasking after this change has not yet been confirmed on the target tablet.**
