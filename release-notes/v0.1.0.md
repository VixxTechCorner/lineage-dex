# Lineage DeX 0.1.0

Experimental prototype / prerelease for Lenovo TB-X306X with LineageOS 20 (Android 13). Independent project; not affiliated with LineageOS or Samsung.

Desktop, app search, saved pins and an optional custom dock. Experimental first build; the custom dock was removed in later versions.
