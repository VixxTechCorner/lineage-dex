# Lineage DeX 0.3.0

Experimental prototype / prerelease for Lenovo TB-X306X with LineageOS 20 (Android 13). Independent project; not affiliated with LineageOS or Samsung.

Redesigned desktop and removed its replacement dock. **Known broken: crashes during startup because the window insets controller is accessed before the window view exists. Archived for completeness; use a later build.**
