# Lineage DeX 0.4.0

Experimental prototype / prerelease for Lenovo TB-X306X with LineageOS 20 (Android 13). Independent project; not affiliated with LineageOS or Samsung.

Added app pairs, window placement requests and recent launches. **Known limitation reported on the target tablet: app pairs can open fullscreen, leaving only one visible.** The size-only requests do not explicitly select freeform mode.
